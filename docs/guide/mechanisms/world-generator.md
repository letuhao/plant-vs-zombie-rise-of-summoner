## Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

| Word | What it actually means here |
|---|---|
| **Vision** | Locked design. Procedural generator and deeper fog craft are not the live map pipeline you rely on today. |
| **World generator** | Procedural maps for the rift — not a lawn level editor and not a random lawn match picker. |
| **Deeper fog craft** | Richer scouting and uncertainty tools beyond basic hold-clear / else-fog. |
| **Shipped fog** | Basic fog of war already plays — this page is the deeper generator/craft Vision on top. |

**Also true:**

- Basic [fog of war](fog-of-war.md) ships now. This page is not a claim that fog is missing entirely.
- Hangs with three-layer presentation and world events as wider Vision.

## Not finished / not playable yet

Do not expect a new procedural world each run as a finished feature.

Play the shipped map and fog; treat generator depth as future craft.

---

## What it is (design)

Procedural maps so the rift can be a place that is made, not only hand-authored once.

Deeper fog craft so scouting stays interesting as empires grow.

```text
  today: playable graph + basic fog
  Vision: generator + deeper fog craft
```

---

## Where it would show up

### On new worlds and scouting

When it ships, generation and craft hang on adventure and prestige of place.

1. Start or continue a world as you do now.
2. Expect richer map birth and scouting tools only when this Vision lands.
3. Until then, use basic fog and End Turn without waiting on a generator panel.

> Not in the current loop yet.

---

## What you do with this page

1. Use the shipped world map and fog today.
2. Do not hunt for a generator settings screen — it is Vision.
3. When a new world starts later, remember generation is design intent, not a promise of today’s builds.

> Stop when generator ≠ “fog is broken.” Live fog: [fog of war](fog-of-war.md).

## Common mix-ups

**Why is every map the same?**  
Deeper procedural generation is Vision. Today’s graph is still the playable adventure.

**Is basic fog Vision too?**  
No. Basic fog ships. This page is deeper craft and generation.

**Does this create lawn levels?**  
No. It is about the rift world map.

**Is this required to End Turn?**  
No. Virtual turns already work on the shipped map.
