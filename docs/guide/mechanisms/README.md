# Gameplay mechanisms

**Status:** index — handbook of discrete systems players learn. Deeper than the [feature list (brief)](../features.md); hangs on [The loops](../the-loops.md).

Pillar pages describe places and topics. **This index** lists every named mechanism. Every row has a full teach guide (markdown + HTML) — blind spots, how it works, first steps, and common mix-ups. Author new teach pages in `_content/*.json` and run `_render.py` (Local control room is still hand-authored until migrated).

Status badges match the [feature catalog](../README.md#feature-catalog): **Shipped** · **WIP** · **Vision**.
