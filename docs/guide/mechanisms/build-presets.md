## In one sentence

---

## Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

| Word | What it actually means here |
|---|---|
| **Vision** | Not playable as a preset system yet. |
| **Preset** | A named saved loadout you can swap — not five independent clicks every time. |
| **Synergy loadout** | Patron + relics + aptitudes + field list together. |
| **Lean** | A build direction (for example fire) you want to reuse. |

**Also true:**

- Until presets ship, change pieces by hand on the rail.
- Hangs on item and power loops — see [The loops](../the-loops.md).

## Common mix-ups

**Can I save presets now?**  
No — Vision.

**Is this the same as species builds?**  
No. Presets store a whole synergy loadout.

**Does it include lawn plants?**  
Fantasy is RPG loadout (patron, relics, aptitudes, field list).

**Broken save?**  
No — feature not shipped.
