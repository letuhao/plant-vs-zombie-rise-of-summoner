## Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

| Word | What it actually means here |
|---|---|
| **WIP** | Not finished. You should not expect a reliable blessing charge meter as a daily loop yet. |
| **Blessing** | A temporary boost to soul earn on following web expeditions after a real lawn run — not a permanent stat and not a second stock. |
| **Idle better** | Design intent: lawn improves the next idle waves. It must never be the only way to keep up. |
| **Required faucet** | What blessing must not become. Souls already pay from play without it. |
| **Web expeditions** | The idle dispatch loop that collects later — see [expeditions](expeditions.md). |

**Also true:**

- Capture and trophies are sibling WIP lawn outcomes — [capture](capture.md) · [lawn trophies](lawn-trophies.md).
- Play lawn for souls and deploy today; treat missing blessing UI as unfinished work.

## Design intent

How it is meant to hang on the loops:

```text
  strong lawn run  ->  blessing charge (WIP)
                         |
                         +->  next web expeditions  ->  stronger soul earn
```

| Piece | What it does |
|---|---|
| **Charge** | A real lawn run builds blessing for what comes next. |
| **Spend on idle** | The next stretch of web expeditions earns souls more strongly. |
| **Not a gate** | Unlocked web play must remain viable without endless lawn. |

---

## What you do today

Play lawn matches and collect expeditions normally.

Do not plan your whole economy around a blessing button that is not live yet.

---

## What you do while it is WIP

1. Earn souls from lawn and expeditions as they already ship.
2. When blessing UI appears, finish a real match first, then collect the boosted idle stretch.
3. If idle ever feels mandatory-only-via-lawn, that is a design bug — report the feel, do not invent a private workaround economy.

## Common mix-ups

**Where is the blessing button?**  
WIP — not finished. Absence is expected.

**Does blessing change combat stats?**  
No. Design is stronger soul earn on following expeditions — not a combat buff.

**Must I lawn forever to keep up?**  
No. Design says a strong run can bless idle — never be the only way to keep up.

**Is this the same as trophies?**  
No. Trophies are cosmetic prestige. Blessing is temporary idle soul pressure.

**Do I still get souls without blessing?**  
Yes. Lawn and other faucets already pay.
