## Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

| Word | What it actually means here |
|---|---|
| **Vision** | Design locked, not in the current loop. You cannot study a finished named-recipe catalog as live play yet. |
| **Named reaction** | A learnable interaction with a name — not a random proc soup and not a seventh element. |
| **Second ring** | What this is **not**. Recipes sit on the existing six-plus-omni ring. |
| **Reaction window** | Interactive battles already talk about windows to react; this page is the shared catalog you can memorize. |
| **Combo recipe** | A short plan players can learn — wet then lightning style — not a secret wiki table. |

**Also true:**

- The ring, shields, and statuses already ship — play those.
- Hands-on reaction feel hangs with [interactive battles](interactive-battles.md) (WIP).

## Not in the current loop

Treat this as future study material on the combat spine.

Do not wait on named recipes to field elements or read statuses.

---

## Design intent

Players should plan interactions, not only read matchup tables.

The list stays short and learnable. It invents no new elements and does not replace the ring.

```text
  element ring (shipped)
       |
       +->  named recipes (Vision)  — learnable list on top
       +->  reaction windows in interactive battles (WIP)
```

---

## What exists around it today

Matchups and statuses resolve now.

Interactive battles will name windows; this catalog is the thing you can study beside them.

## Common mix-ups

**Where is the recipe book?**  
Vision — not shipped. You cannot open it as a live system yet.

**Does this add new elements?**  
No. Design forbids a second ring and new colours.

**Is this the same as statuses?**  
No. Statuses already resolve. Named recipes are a learnable interaction list on top of the ring.

**Do I need a wiki?**  
Design wants a short shared list — not a secret table.

**Are reaction windows Vision too?**  
Windows belong to interactive battles (WIP). This page is the named catalog (Vision).
