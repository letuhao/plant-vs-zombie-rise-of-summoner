## Common mix-ups

**Is World travel the finished stage?**  
No. Travel opens the thin graph. Finished stage place is Vision.

**Does the stage use a diary calendar?**  
Design shows a calendar in the HUD fantasy; time still resolves on virtual turns, not a real-life meta-clock.

**Are buildings Vision too?**  
Buildings are WIP; the finished stage place is Vision.

**Is this a different clock from the map?**  
No. Same End Turn / virtual turns.
