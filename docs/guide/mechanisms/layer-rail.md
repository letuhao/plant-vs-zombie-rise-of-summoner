# Layer rail and hotkeys

**Status:** Shipped
**Loop:** Session — how you play — see [The loops](../the-loops.md)
**Pillar:** [Sanctum](../sanctum.md)

## What it is

Creatures, Commanders, Relics, Fusion, Pacts, Expeditions, Almanac, Chronicle — the same keys everywhere over whatever stage you are on.

## How you use it

Use C / K / R / F / P / E / A / H (and Esc for System). Closing a layer returns you to the stage you left.
