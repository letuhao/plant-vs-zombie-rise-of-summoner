# Title and save select

**Status:** Shipped
**Loop:** Session — how you play — see [The loops](../the-loops.md)
**Pillar:** [Sanctum](../sanctum.md)

## What it is

At the door you pick or create a summoner save. That save is the world you keep.

## How you use it

On boot, choose an existing save or create one. Updating the RPG keeps that data and does not touch the lawn game's own saves.
