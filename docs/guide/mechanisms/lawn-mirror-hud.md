# Live mirror and unit HUD

**Status:** Shipped
**Loop:** Lawn — first core — see [The loops](../the-loops.md)
**Pillar:** [The lawn](../the-lawn.md)

## What it is

Watch the 12x5 board in the browser. Unit HUD shows identity, shield, and statuses above each unit.

## How you use it

With a match running, open Lawn. Read the mirror and HUD under pressure without opening a second physics engine.
