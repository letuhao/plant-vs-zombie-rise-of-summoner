## Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

| Word | What it actually means here |
|---|---|
| **WIP** | Not finished. You should not expect a full creature-sheet loadout editor as a daily loop yet. |
| **Loadout** | The small set of actions on a creature — not a second character class. |
| **Unlock** | Getting a skill is progression. It is not a second power curve beside levels and aptitudes. |
| **Cost** | Skills will spend [actor meters](actor-meters.md) you can see — when that loop lands. |
| **Guard / reaction** | Guard, movement skills, and reaction windows belong with meters and interactive battles — still WIP. |

**Also true:**

- Live power today is levels, traits, elements, and [aptitudes](aptitudes.md) — play those.
- Hands-on turns that use skills: [interactive battles](interactive-battles.md) (also WIP).

## Not finished yet

Loadouts will live on the creature sheet.

Until the editor and spend loop ship, treat missing skill slots as unfinished work.

---

## Design shape

What the page is aiming at:

```text
  unlock skill (progression)  ->  equip on sheet  ->  spend meters / cooldown in fight
```

| Piece | What it does |
|---|---|
| **Innate** | Actions the creature brings by nature. |
| **Family** | Actions shared by a kinship of species. |
| **Signatures** | Standout actions that define the specimen’s face. |

> Unlocking is progression — not a parallel grind that replaces levels.

---

## What you do today

Raise specimens, field elements, and fight with the combat language that already ships.

Read this page so the future sheet vocabulary is not a surprise.

---

## What you do while it is WIP

1. Grow roster power with levels, fusion, and aptitudes now.
2. When loadout UI appears, equip a small set — do not hunt for a class pick.
3. Treat skill unlocks as progression steps, not a second curve to max first.

> Meters that pay costs: [actor meters](actor-meters.md). Specimen home: [specimens](specimens.md).

---

## Common mix-ups

**Where is the skill loadout screen?**  
WIP — not finished. Absence is expected.

**Is unlocking a skill a second power ladder?**  
No. Design says unlocks are progression, not a second curve.

**Do I pick a class for skills?**  
No. You have no class. Loadouts sit on the creature.

**Will skills invent new elements?**  
No. They spend meters and use the existing combat language.

**Are expeditions waiting on this?**  
No. Expeditions can stay auto-resolve; skills matter most when you pilot turns.
