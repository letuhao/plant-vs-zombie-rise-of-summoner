**Status:** Shipped
**Loop:** Summon and fusion — see [The loops](../the-loops.md)

## What it is

Spend souls for new demons. Pity is shown on the altar. Gacha is one path, never the only one.

## How you use it

Open Summon / Demons when you have souls. Pull; read pity; add specimens to the roster.
