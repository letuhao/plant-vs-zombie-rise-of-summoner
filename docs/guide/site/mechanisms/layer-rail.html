Layer rail and hotkeys

The layer rail is the shared set of menus and hotkeys — Creatures, Fusion, Expeditions, and the rest — that open over whatever stage you are on.

Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

Rail
Not a train. The fixed list of layers and keys available from any stage.
Layer
A panel drawn over the current stage. Closing it returns you exactly where you were.
Hotkey
One letter (or Esc) that opens that layer. Same letter on Sanctum, lawn, or map.
Stack
Layers can pile up. Esc closes the top one; on an empty stack, Esc opens System.
  • Locked layers stay visible and say what unlocks them — see unlock beats.
  • You are usually standing in the Sanctum when you first learn the rail.

The keys

Memorize the verb, not a different shortcut per screen:

Key Layer
C Creatures
K Commanders
R Relics
F Fusion
P Pacts
E Expeditions
A Almanac
H Chronicle
Esc Close top layer; on empty stack → System

Travel to the world map is M — that changes stage, it is not a layer on the rail.

How it feels

Open Creatures mid-hall, check a demon, close — you are still in the Sanctum.

The same C works if you later open the rail from another stage. You do not learn a second UI language.

  [ stage: Sanctum / Lawn / World ]
           ^
           |  open C / F / E / …
           v
  [ layer over the stage ]  --Esc-->  back to stage

What the rail is not

It is not a website sidebar of separate pages you navigate away to.

It is not the lawn game’s own pause menu — that is the host pack. This rail is Rise of Summoner’s control-room chrome.

What you do (first time)

  1. In the Sanctum, press C — Creatures should open over the hall.
  2. Press Esc (or the close control) and confirm you are still in the Sanctum.
  3. Press ? or open System and confirm the keymap matches this table.

Stop when one key feels global. Next: unlock beats so locked entries make sense.

Common mix-ups

Why can’t I open Relics yet?
It unlocks when you hold your first item. The entry should say so — see unlock beats.
Is Fusion the host game’s name?
No. On the rail, Fusion (F) is specimen merge. The host pack is Plants vs. Zombies: Fusion.
Does Esc always quit the game?
No. Esc closes the top layer first. Only on an empty stack does it open System (quit lives there).
Is M on the rail?
M travels to the world map — a stage change, not a layer.
Do keys change on the lawn stage?
No. Same rail letters. That is the point of one rail.
