Build presets

Vision: save a synergy loadout — patron, relics, aptitudes, who you field — so a lean is something you keep.

Blind spots (if you are new)

These words get guessed wrong. Read them once before the rest of the page.

Vision
Not playable as a preset system yet.
Preset
A named saved loadout you can swap — not five independent clicks every time.
Synergy loadout
Patron + relics + aptitudes + field list together.
Lean
A build direction (for example fire) you want to reuse.
  • Until presets ship, change pieces by hand on the rail.
  • Hangs on item and power loops — see The loops.

Fantasy

Save “Fire lean” once.

Swap to it later without redoing every panel.

What you do today

Set commanders, aptitudes, and gear as each surface allows.

Treat missing preset UI as Vision, not corruption.

What you do with this page

  1. Ignore absent preset buttons.
  2. Build with live aptitudes and roster tools.
  3. Return here when presets ship.
