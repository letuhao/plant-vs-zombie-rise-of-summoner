# Player guide site

Static HTML skim of the Rise of Summoner vision — tabs over one stage, soil theme, keyboard-friendly.

**Mirrors guide version 12** (see [`../README.md`](../README.md)).

**Open:** double-click [`index.html`](index.html), or serve the folder locally. No build step.

**Tabs:** Welcome · The loops · Features · Mechanisms · How you play · Win & lose.

**Mechanisms tab** indexes every handbook system. Every row links to a teach page under [`mechanisms/`](mechanisms/) (authored via `../mechanisms/_content/` + `_render.py`, except hand-authored [Local control room](mechanisms/local-control-room.html)).

**Markdown SSOT:** parent [`../`](../) — especially [`features.md`](../features.md), [`the-loops.md`](../the-loops.md), [`mechanisms/`](../mechanisms/), and the [full catalog](../README.md#feature-catalog). This site does not invent a parallel pitch.
