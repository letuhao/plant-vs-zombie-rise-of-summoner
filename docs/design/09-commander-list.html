Commanders

The player empire's commanders — who leads your legions on the world map and whose auras reach the lawn. Today that roster is one person: Crazy Dave. The list is the missing door into the same Actor sheet creatures use, with commander-only tabs (aura loadout, banner, account-wide aptitudes). It also carries the persisted default lawn commander (Crazy Dave initially, swappable when the roster grows — never a pre-run gate), plus stubs for map location and legion detail — reverse hooks for when the world map ships so you can monitor a commander and their legion from here. This plate does not re-spec auras; the aura-skill program already owns that stack.

A · Why a list — and whose commanders belong here

Dave is implicit everywhere today: Sanctum skips straight to the lawn, aptitudes assume one commander, loadout APIs key to the player id with no picker. That worked while there was only one commander and no menu — it fails the moment the empire can field more than one leader or the player needs to review aura loadout before a run.

Empire boundary, not a global roster. Two empires exist on the Two Hearths world map from the first campaign gate — Dave's hearth and Zomboss's fortress cluster — but the player manages their empire's commanders here. The opposing commander is map and AI data, the same way you do not edit the enemy's creature roster in your Creatures layer. Symmetric loam rules on the map do not mean symmetric UI.
Not the Aptitudes rail layer. Primary Stats (◎) remains a fast-path into commander-scope point spending. This list answers which commander and opens their full sheet — identity, loadout, banner — not "how many points in Might."

D · Async default — no pre-run gate

The lawn run is led by one commander, but the web FE never blocks play to ask who. The save carries a persisted default (Crazy Dave on first launch). The player changes it here when they want — not before every match. Sanctum's Defend the lawn and the PvZ game menu are separate clients; the overlay reads the same default asynchronously when a match starts, the same shape as aptitude polling today.

No pre-run dialog for commander. We do not add a commander row to plate 07 §A or force a web step before the game menu runs. Creature loadout in 07 is a separate concern — also async where the dual-client constraint applies.
Strip, footer, and sheet buttons are mirrors, not gates. They all read or write the same persisted default. None of them block play if the player never opens this layer.
Active aura ≠ default commander. Loadout and runtime toggles live on the Actor sheet Actions tab. Default names who leads; which aura is live follows that commander's save.

E · Location and legion — map reverse stubs

When the world map ships, the player monitors commanders and legions on the map — sector markers, march lines, fog. This list is the reverse hook: each row shows where that commander sits on the map and which legion they lead, so you can jump map ↔ roster without re-searching. Neither path is built yet; both render as honest stubs (GG-17).
