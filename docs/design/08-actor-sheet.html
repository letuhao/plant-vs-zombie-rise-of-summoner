Actor Sheet

One centralized character menu, not five scattered surfaces. Today a specimen's progression, primary-stat distribution, derived stats, actions and passives each live in a different place (or nowhere) — Primary Stats is its own rail layer, derived stats has a locked spec but zero render path, actions/passives have no menu at all outside live battle. This plate proposes the single door: open one specimen, see everything about them, some sections already playable, some visibly locked with the real reason why (GG-17). Commanders use the same shell with role extensions — aura loadout, banner, account-wide aptitudes — drawn in §I; see also plate 09 for the list that opens this panel.

A · Why one door, not five

Reference sweep before drawing anything: Diablo 4's character screen pairs four primary attributes with the derived combat stats they produce, on one screen — attributes are never shown without their consequence. Baldur's Gate 3 keeps Abilities/Skills/Inventory/Spellbook as tabs of one character sheet, not five separate menus, and visibly separates "known" from "prepared/equipped" wherever a creature knows more than it can use at once. Path of Exile keeps its passive tree a deliberately separate, deep surface from the character panel — useful here as a warning, not a pattern to copy: this game's action/passive lists are small enough that a full skill-tree canvas would be over-engineering. What's worth keeping from PoE is purely the locked-node treatment — dim, dashed, dead center on "here's what unlocks it," a small notable/keystone size distinction for bigger-effect nodes.

F · Passives — locked, small, not a Path-of-Exile tree

Passive skills are the owner's own explicitly deferred sub-feature ("will be added later," no module id, no spec). PoE's tree works at PoE's scale — thousands of nodes across a shared web. This game doesn't have that scale of content, and won't for a long time, so the honest draft is a small locked grid with a notable-sized node reserved for whenever one big passive exists — not a scaffold for a tree this game may never need.

🌱Root Deep
☀Sunlit
🌻Bloom Everlasting

Nothing here is a commitment to a node-graph passive system. A flat locked list would show the same honesty with far less to build; the small notable-node treatment is included only because the owner's own list named "passive skills" as a thing this sheet locks, not because a tree-shaped passive system has been decided anywhere.

G · Gear — real slots, empty is the honest state today

equipSlots is already typed on ActorView, already unconditionally "pending" from the same adapter as derived stats. Unlike Actions/Passives this is not level-gated — it's just genuinely empty because no acquisition system exists yet, so the right state is an honest empty-state, not a lock icon (locks imply a gate; there isn't one here, only "nothing to equip yet").

⛭ No gear slots wired yet Equipment has its own spec (spec-equip-and-paperdoll.md) — this tab is the doorway into it once that system has a server endpoint, the same relationship this plate gives Derived Stats.
