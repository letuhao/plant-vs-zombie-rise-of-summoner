B · Deploying — the targeting mode

The lawn's interaction FSM has a SpawnTargeting state that no plate had drawn. It is stage chrome, not a layer: the player is choosing a cell on the board, so the board must stay fully visible and fully interactive.

The ghost is chrome, not an occupant. The lit cells and the held creature are UI state only — nothing is spawned, nothing is spent, and the board's living set is untouched until the server admits the placement. That is the architecture's rule about optimistic living entities, drawn. GG-15
Why this is not a layer. The player is acting on the stage, so a scrim and a panel would be exactly wrong. Targeting is the one interaction that must never dim the thing it is aiming at.

C · The offer — the only other thing that wants to interrupt

A demon offering a pact is the most tempting candidate for a blocking dialog, and it does not get one. Only run results may take band 3 unprompted; the offer arrives at band 4 and waits. GG-53 · D6

How it arrives — a toast, mid-anything

👹Something is offering termsIt will wait in the sanctum. Pacts P
It does not open itself. A pact is a decision the player should make when they choose to, not one ambushed into them mid-wave.

D · The first session, all four beats

Plate 01 drew beat one and stopped. GG-43 says the first session is authored, so here is the whole script — what appears, what is deliberately absent, and what unlocks at each step.

BeatWhat the player seesWhat they doWhat appears afterwards
1 An empty sanctum and one sunflower that "answered". Six of eight rail entries locked. Name it. Bind it. Creatures unlocks. The run prompt appears.
2 The loadout, with one creature and two empty berths — so the shape of a party is visible before it can be filled. Begin the first night. The lawn stage. No panels are suggested; the rail is present but quiet.
3 The first wave. When the first zombie takes elemental damage, one line appears beside it: "Fire is strong against Ice." Once. Survive, or not — both are authored outcomes. Run result. Chronicle and Almanac unlock.
4 Back in the sanctum, the focus card reads "Your first relic fell where you fought." Collect it. Relics unlocks. The tutorial is over; nothing further is scripted.

E · Focus and directional input

GG-19 and GG-57 were declared and never drawn. Focus order is a design decision — left to the DOM it produces the order the markup happened to be written in.

A grid is one tab stop, not four hundred. Tabbing through a thousand cards is the reason keyboard support gets abandoned. Enter the grid once, then move inside it with arrows. GG-19 · GG-57

Directional movement inside a grid

◉

Arrows move spatially. At an edge, focus stops rather than wrapping — wrapping in two dimensions is disorienting and there is no undo for "where did my selection go".
