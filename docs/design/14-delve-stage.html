#/delve/{delveId}, the sixth stage (decisions.md: “Game GUI — sixth stage delve”, 2026-09-05). The room graph is the stage; a fight is drawn on it; the pack, wild talk, event, object prompt, supply bag and fight input are band-2 panels over it, alongside the Sanctum’s own descent picker; one extraction summary closes a run; drops, level-ups, joins and first clears report without stopping anything. Governed by party-dungeon-ideal.md (the ideal that names this deliverable, §7: “The stage needs a design plate under docs/design/; this document names the stage and its HUD, not their pixels”) and party-dungeon/spec-delve-stage.md (the module spec; §7 is the bands-and-surfaces table every section below is keyed against).

Drawn after the code, not before it. Every surface on this plate is grounded against the real web/fusion-rpg-web/src/stages/delve/ and src/layers/delve/ components this program shipped on 2026-09-07 (D5.1, D5.4–D5.10, D5.12, all closed) — their own doc comments, their real prop types, and a live browser check against the bundled fixtures/first-descent.json fallback (no server required; DelveStage.tsx falls back to it whenever GET /api/delve/{id} has no data, which is every real id today). The one piece still genuinely unbuilt is D5.11, the live session client — see §I. Where a real, honestly-named gap survives in the shipped code, this plate keeps it: a wiring or real badge here is not a to-do list, it is what the working tree actually says today.

Why Descend is built but Extract/Retreat are wiring, though all three are equally real and tested. Descend is reachable end to end: the picker (§E) really calls it, and a real (if always-refused today) POST /api/delve/start follows. Extract and Retreat are pure, real, tested components with zero callers anywhere in this codebase — the “declare extract/retreat” order is a live-session decision (§9), and D5.11 (§I), the client that would call them, does not exist yet.

The one root cause behind almost every wiring badge on this plate: D5.11, the live session client. subscribe · steer · declare · freeze · resume · reconnect — src/stages/delve/session.ts does not exist. Its server half (D2.16) is separately, honestly still blocked: no concurrency primitive for a mid-battle pause/resume has ever been built for any profile, siege included. Connection state, the initiative rail, the fight-in-place live data, the Fight input panel, and the Extract/Retreat confirms are all real, tested, and correctly built against the real contract shapes (FightView, DelveConnectionStatus) — every one of them is a finished component waiting on this exact module, not an unfinished one.

What this plate does not decide. Any number — every figure shown here is a real, live fixture value, never a balance decision. Rung/band display wording (no registry exists yet — §E). Whether a live PvZ lawn ever becomes a room kind (party-dungeon-ideal.md §7 — the injector’s kernel drive is sequenced last, in its own program). Pixels beyond layout fidelity — colour, spacing and type all come from _kit/tokens.css unchanged; nothing here is a new design-system decision.
