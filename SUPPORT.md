# Support — Rise of Summoner

## Players

1. Download the latest **[GitHub Release](https://github.com/letuhao/plant-vs-zombie-rise-of-summoner/releases)** (`FusionRpg-win-x64.zip`).
2. Follow [docs/runbook/players.md](docs/runbook/players.md).
3. Use **Browse** to select your legal game folder (folder with `PlantsVsZombiesRH.exe`). Do not expect hardcoded machine paths.
4. If BepInEx is missing, use **Install BepInEx** in the launcher (official GitHub only). Dual-load with MelonLoader is refused.
5. **Antivirus:** builds are unsigned hobby OSS. First-run **Allow** acknowledges that. Use **Prepare Windows Security** for Microsoft Defender (UAC). For Bitdefender and others, restore from quarantine and exclude the FusionRpg folder yourself — see [Trust & antivirus](docs/runbook/players.md#trust--antivirus-unsigned-hobby-builds). Do not turn antivirus off entirely.

Open a [bug report](https://github.com/letuhao/plant-vs-zombie-rise-of-summoner/issues/new/choose) only after checking the runbook and attaching launcher / BepInEx log snippets.
